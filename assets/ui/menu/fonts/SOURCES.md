# Cinzel

Local Latin subset of Cinzel, by Natanael Gama, under SIL Open Font License 1.1 (OFL.txt). Source: https://github.com/google/fonts/tree/main/ofl/cinzel . Downloaded 2026-11-17.

Rebuild with fontTools: `pyftsubset "Cinzel[wght].ttf" --output-file=cinzel-latin.woff2 --flavor=woff2 --unicodes="U+0000-00FF,U+0100-017F,U+2000-206F,U+20AC" --layout-features="*"`. No font CDN is contacted by the menu.
